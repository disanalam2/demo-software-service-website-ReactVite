## 📖 Overview

Built leveraging the power of React 18 and Vite, this platform delivers lightning-fast hot module replacement during development and highly optimized, minified bundles for production. It features complex state management, dynamic component rendering, and an immersive user interface crafted with Tailwind CSS.

## ✨ Key Features

- **Global State Management:** Utilizes React Context API to solve prop drilling and dramatically simplify the component architecture.
- **Vite Build Optimization:** Highly optimized Rollup configurations to appropriately chunk vendors and transpile legacy packages for seamless deployment.
- **Dynamic Tailwind Styling:** Safelisted dynamic UI classes for robust production builds without unexpected CSS purging.
- **Blazing Fast Performance:** Near-instant page transitions and lightning-fast FCP (First Contentful Paint).

## 🛠 Tech Stack

- **Frontend Core:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** Context API
- **Routing:** React Router DOM
- **Hosting/Deployment:** Firebase Hosting

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/disanalam2/demo-software-service-website-ReactVite.git
   ```
2. Navigate to the project directory:
   ```bash
   cd demo-software-service-website-ReactVite
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Build for production:
   ```bash
   npm run build
   ```
