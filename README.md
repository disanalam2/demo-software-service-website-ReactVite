# Software Services Website

A modern, responsive portfolio and service showcase website built with React and Vite. This project demonstrates professional web development practices with fast development experience and optimized production builds.

## 🚀 Features

- **Fast Development**: Vite provides instant hot module replacement (HMR) for rapid development
- **React 19**: Modern React with the latest features and optimizations
- **Responsive Design**: Mobile-first CSS design for all device sizes
- **Code Quality**: ESLint configuration for consistent code standards
- **Production Ready**: Optimized build process for deployment

## 📋 Project Structure

```
src/
├── App.jsx              # Main application component
├── App.css              # App styling
├── main.jsx             # Entry point
├── index.js             # JavaScript utilities
├── index.css            # Global styles
├── contact.css          # Contact page styling
└── services.css         # Services page styling
public/                  # Static assets
```

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd demo-software-service-website-ReactVite
```

2. Install dependencies
```bash
npm install
```

### Development

Start the development server with HMR:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build

Create an optimized production build:
```bash
npm run build
```

### Preview

Preview the production build locally:
```bash
npm run preview
```

### Code Quality

Lint the codebase:
```bash
npm run lint
```
